# Cloud Computing Reflection

Cloud computing has become an essential part of my daily life even before I fully understood its concepts. Many of the applications I use every day rely on cloud services to provide convenient access to data, communication, and entertainment.

One cloud service I frequently use is **Google Drive**. It follows the **Software as a Service (SaaS)** model because users simply access the application through a web browser without managing servers or software. It is deployed through a **Public Cloud** since millions of users access the same cloud infrastructure over the internet.

Another service I use is **Facebook Messenger**. Like Google Drive, Messenger is also **SaaS** because Meta manages all servers, software, and updates while users only access the messaging application. It is also considered a **Public Cloud** service because it is available to anyone with an internet connection.

The third service I regularly use is **Canva**. Canva provides online graphic design tools through the browser, making it another example of **SaaS**. Since it serves millions of users worldwide using shared infrastructure, it also belongs to the **Public Cloud** deployment model.

Version control is very important in cloud computing because multiple developers often work on the same project at the same time. Without version control, files could easily be overwritten or lost. Git solves this problem by recording every change made to a project. GitHub makes collaboration easier by allowing developers to push updates, review changes, create branches, and merge code safely. It also provides a complete history of the project, making it easier to recover previous versions if mistakes happen.

Overall, this activity helped me understand how cloud computing is already part of my everyday life and how Git and GitHub are essential tools for organizing projects, collaborating with others, and managing changes efficiently.
